日语轻小说模式

  • 左键点击文本段落，复制原文并翻译。
  • 启用 DeepSeek 时，一次请求同时显示译文和词语级假名原文行。
  • 右键点击高亮句子，复制该句。

常规翻译模式

  • 手动选中任意网页文本，再点击选区旁的翻译按钮。
  • 只显示译文，不标注假名，也不会提示或接管段落点击。

小技巧

  • 点击翻译结果旁的小三角，展开或收起该段的假名标注和译文。
  • 开启「保存翻译结果」后，刷新页面再点击相同段落会优先读取本机缓存。
  • 「翻译」页的「清除缓存」可随时一键清除本机已保存的译文。
  • DeepSeek API Key 可在 DeepSeek Platform ↗ 创建。
